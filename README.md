# Waynotes

Waynotes is a World of Warcraft addon for **WoW Forever**. It provides a WoW-style quest tracker and a standalone leveling guide with curated Forever routes.

## Install

1. Download the latest release zip (`Waynotes-<version>-forever.zip`).
2. Extract it into your Forever `Interface\AddOns` folder so you have:

   `World of Warcraft\_forever_\Interface\AddOns\Waynotes\`

3. Restart the client (or `/reload`) and enable **Waynotes** in the AddOns list.

### WowUp

Install from the GitHub repo URL with the Forever client selected. Release assets must end in `-forever.zip` so WowUp can verify Forever compatibility.

## Optional addons

- **QuestieDB** - quest names, givers, and map pins
- **WhatsTraining** - trainer reminder support

## Usage

- Open options from the minimap button or with `/waynotes`
- Pick a guide from the tracker menu (right-click the tracker)
- Common commands: `/waynotes guides`, `/waynotes next`, `/waynotes back`
